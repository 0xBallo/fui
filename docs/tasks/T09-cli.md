# T09 — CLI (cobra, renderers, errors, agent mode, help --json)

Branch `feat/cli`. Owned path: `internal/cli/`. Read `AGENTS.md` first, then the merged `internal/app` (Service:
Plan/Apply use cases, request types that take user-typed strings, `Codes()`), `internal/app/reporting`,
`internal/domain` (`Codes()`, `Error`), `internal/config` (Get / SetInFile, Flags), `internal/testutil/memstore`.
`internal/cli` imports only `app`, `app/reporting`, `domain`, `config` — never `store` or `connector`.
Spec refs: technical spec "CLI" (structure, Plan/Apply, output formats, exit codes, name refs, agent mode),
"Golden file come contratto"; functional spec "Requisiti funzionali — CLI", "Uso con agenti AI".

## Deliverables

1. **Tree** with `spf13/cobra`, one file per command `<noun>_<verb>.go`, ≤ 60 lines each, no business logic:
   `init`, `add`, `tx list|show|edit|rm`, `transfer`, `account add|list|show|edit|archive`,
   `category add|list|rename|merge|rm`, `fx set|list` (MVP needs manual rates; not in the FS table — document it),
   `report run categories|cashflow`, `kpi runway`, `backup`, `restore`, `config get|set`, `help --json`,
   `completion bash|zsh|fish`, `--version`. `fui` with no args must call an injected `RunTUI` func.
   **Not here**: `import`, `export`, `connector` (added later by T08), `skill` (T11).
2. **Dependencies injected** via a `cli.Deps` struct (app service, reporting use cases, config, stdin/stdout/
   stderr, isTerminal, RunTUI, version) built by the composition root later; tests build it on memstore.
3. **Persistent flags**: `--json`, `--csv`, `--no-input`, `--dry-run`, `--yes`, `--db`, `--verbose`.
   `FUI_AGENT=1` ⇒ `--no-input --json` and any write without `--yes` fails with `confirmation_required`.
   Writes: Plan → if `--dry-run` render plan and exit 0 → else Apply; if `Plan.Bulk` and a terminal is present ask
   confirmation (huh) unless `--yes`; with `--no-input`/no TTY a bulk write without `--yes` fails
   `confirmation_required`. Missing required fields: prompt with `charmbracelet/huh` only on a TTY without
   `--no-input`, else `missing_field`.
4. **Renderers** separate from commands: table (aligned, amounts per locale, colors only on TTY and without
   `NO_COLOR`, minus sign on outflows), `--json` (arrays for lists, objects for details, snake_case, amounts as
   integer minor units + `currency`, dates `YYYY-MM-DD`), `--csv` (RFC 4180, header, dot decimal). Plans render
   for `--dry-run` in all three formats.
5. **Errors**: ONE function mapping error → exit code (0 ok, 1 user input: invalid_amount, ambiguous_name,
   missing_field, confirmation_required, …; 2 data/IO: db_locked, db_corrupted, connector_failed,
   migration_failed, …) with a test enumerating `domain.Codes()` + `app.Codes()`. With `--json` errors go to stderr
   as `{"error":{"code","message","details"}}`.
6. **`fui help --json`** generated by walking the cobra tree (commands, flags, args, examples, output schema
   names); golden file. Every command has `--help` with at least one example.
